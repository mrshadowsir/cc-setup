🟦 Termux (Android)

1
Termux F-Droid se install karo

Play Store wala purana hai.

2
Packages list update
pkg update -y
3
Packages upgrade (zaroori)
pkg upgrade -y
4
git aur curl
pkg install -y git curl
5
Repo download
git clone https://github.com/mrshadowsir/cc-setup ~/cc-setup
6
Installer chalao
bash ~/cc-setup/install.sh
7
Agli baar sirf
ccs
⚠️ pkg update fail ho to termux-change-repo chalao, mirror badlo, phir step 2.
🛠 Error: CANNOT LINK EXECUTABLE ... SSL_set_quic_tls_early_data_enabled ya fatal: remote helper 'https' aborted?
Ye purane aur naye packages ka mismatch hai. Step 3 (pkg upgrade -y) chalao, phir ye ek command:
pkg reinstall -y libcurl git curl
💡 Phir bhi na chale to repo ZIP se lo (ye bhi curl par chalta hai):
curl -L -o ~/cc.zip https://github.com/mrshadowsir/cc-setup/archive/refs/heads/main.zip
pkg install -y unzip && unzip -o ~/cc.zip -d ~ && mv ~/cc-setup-main ~/cc-setup

🟨 Plugin Center

Dashboard me 🧩 Plugins tab kholo. Upar 5 sections hain:

SectionKya milega
🛒 MarketplaceSaare plugins. Search. Install ek click, 🗑 Delete ek click me permanent.
✅ InstalledActive / OFF / Files gayab. ON/OFF toggle, Sab ON/OFF, Health check.
🔧 CustomOfficial ke bahar ke plugins. Marketplace jodo, plugin@marketplace se install.
🧪 AdvancedBackup / restore, marketplace update, skills ki list.
📦 Recommendedplugins.json ki recommended list.
Pehli baar Marketplace me neeche Official marketplace jodo dabao.
🚨 Permanent delete me plugin ki files, cache aur settings entry sab hat jati hai. Wapas nahi aata, isliye confirm popup aata hai.

Status ka matlab

● Active installed + ON + files maujood. Kaam kar raha hai.

⏸ OFF installed hai, par band hai.

⚠ Files gayab settings me hai, folder nahi. Reinstall ya Delete karo.

⚠️ Known limits

• Termux par Claude Code 2.1.112 pin hota hai. Badalna ho to CC_CLAUDE_VER set karo.
• Android battery system phone ke hisaab se alag hai. ccs battery dobara chalao.
• Free providers ke models roz badalte hain. Hub > Models me dobara test karo.
• Kuch free providers prompts training me use kar sakte hain. Private code/data mat bhejo.
• Plugin status naye Claude session me lagta hai.
