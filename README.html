🏁 Ye kya hai?

ccs ek chhota tool hai jo tumhare phone ya computer par Claude Code chalata hai, free AI models se jodta hai, aur ek rang-birangi dashboard deta hai. Terminal band karne par bhi background me chalta rehta hai.

Poora flow (ek nazar me)

1️⃣ Install→2️⃣ ccs likho→3️⃣ Dashboard me key + model→4️⃣ ccs claude→5️⃣ Preview me dekho

Kuch bhi pehle se aana zaruri nahi. Neeche har step alag se samjhaya hai. Command box me Copy dabao, terminal me paste karo, Enter dabao. Bas.

Teen aasan shabd

  • Terminal: wo kaali screen jahan command likhte hain. Mobile par Termux app, Windows par VS Code ka terminal, Linux par normal terminal.
  • Command: ek line jo terminal me paste karke Enter dabate hain.
  • Dashboard: browser me khulne wala control panel (ccs likhne par khud khulta hai).

⬇️ Install karo

Upar se apna device chuno. Sirf usi device ke steps dikhenge. Har step ek ek karke chalao.

📱 Android (Termux)

Termux sirf F-Droid se install karo. Play Store wala purana hai aur kaam nahi karta.
  1. Termux kholo
    F-Droid se install karke app kholo. Kaali screen aayegi, wahi terminal hai.
  2. Ek command me install
    Ye git aur curl lagata hai aur ccs install kar deta hai.
  3. Agar "pkg update" fail ho
    Mirror badalna padta hai. Ye chalao, ek mirror chuno, phir upar wala install command dobara chalao.
  4. Dashboard khulne ka intezar karo
    Browser apne aap khulta hai. Na khule to terminal me diya hua link copy karke browser me paste karo.

🪟 Windows + VS Code

  1. Node.js lagao
    VS Code me Terminal > New Terminal kholo (ya Start me PowerShell).
  2. Git lagao
  3. Dono ke baad VS Code poora band karke dobara kholo, warna naye commands nahi milenge.
  4. ccs download karo
  5. Install chalao
    Ye ccs command bana deta hai aur dashboard kholta hai.

🐧 Linux

  1. Node.js 18 ya naya chahiye. Pehle check karo:
    Version 18 se kam ho ya "not found" aaye to neeche se ek tareeka chuno.
  2. Node + git lagao (apne distro ka chuno)
    Ubuntu / Debian
    Fedora
    Arch
    Koi bhi distro: nvm se (recommended agar purana Node mila)
  3. ccs install karo
  4. Agar "ccs: command not found" aaye
    Matlab ~/.local/bin PATH me nahi hai. Ye jodo, phir terminal dobara kholo.

🚀 Pehla setup (dashboard me)

Install hote hi dashboard khulta hai. Na khule to terminal me ye likho:

  1. Claude Code install
    Home tab ke Step 1 me Install dabao. (Terminal se chahiye to neeche command hai.)
  2. API key daalo
    Home > Gateway me provider chuno, URL aur key paste karo, Save. Free key chahiye to 🆓 Free API keys lo dabao.
  3. Model chuno
    Hub tab > Models > Refresh, phir ⚡ Test se check karo aur Lagao dabao.
  4. Claude chalao
    Teeno step hote hi terminal me:
Home tab ka 🩺 Health check dabao. Wo batata hai kya baaki hai aur kaise theek karna hai.

⌨️ Roz ke commands

Ye sabse zyada kaam aate hain. Pehle inhe yaad kar lo.

🤖 Claude chalana

Do tareeke hain. Dono me model fail ho to dashboard par laal box aata hai aur kaam wahin se aage badhta hai.

Tareeka 1: Terminal me (chat jaisa)

Hamesha ccs claude likho. Seedha claude mat chalao, kyunki asli key settings me nahi rakhi jaati.

Tareeka 2: Dashboard ke Task tab se (background)

  1. Task tab kholo, Project folder ka poora path likho.
  2. Kya banana hai me likho, jaise: "todo app banao, tests likho".
  3. ▶ Task chalao dabao. Live output wahin dikhta hai. Screen band ho tab bhi chalta hai.
Beech me ruk jaye to purane tasks me Jaari rakho dabao, wahin se aage chalega.

👁️ Live Preview

Dashboard ka Preview tab tumhara banta hua app/website turant dikhata hai, bilkul VS Code ke live preview jaisa. Claude file badalta hai aur preview 1 second me apne aap update ho jata hai.

Kaise use karein

  1. Preview tab kholo (neeche ka 👁️ button).
  2. Folder likho jahan project hai (naya ho to ➕ Naya folder banao dabao). Task chalate hi ye apne aap set ho jata hai.
  3. Kya banana hai likho aur ▶ Banao dabao. Jaise jaise files banti hain, preview badalta jata hai.
  4. Preview ke andar click, scroll, type karo, asli app ki tarah check karo.

⚡ Hub: models, free API, OmniRoute

Dashboard ke Hub tab me teen hisse hain.

🤖 Models

Jin providers ki key save hai unke sab models ek list me. Search karo, ⭐ favorite banao, 📋 Copy se naam copy karo, ⚡ Test se check karo aur Lagao se seedha Claude me lagao.

🆓 Free APIs

16 free providers (Gemini, Groq, OpenRouter, Cerebras, Mistral, NVIDIA, Cloudflare wagairah). Card kholo, API key lene jao, key paste karo, Save, phir Key test. Bina key wale (Kilo, LLM7, OVH, Ollama) ko ➕ Hub me jodo dabao.

Cloudflare ke URL me {account_id} ki jagah apni asli Account ID likho. Kuch free providers prompts log kar sakte hain, private code mat bhejo.

🛰️ OmniRoute

Ek hi local gateway jo kai free providers ko ek endpoint par jodta hai. Dashboard se Install, Start aur Claude se jodna ho jata hai. Terminal se chahiye to:

OmniRoute ko Node 22 ya 24+ chahiye (23 nahi). Node version check karne ka command Install section me hai.

🔋 Battery restriction hatao

Android kabhi kabhi background kaam maar deta hai. Ye ek baar kar lo (1 minute) to ccs bina ruke chalta rahega.

  1. Settings > Apps > Termux > Battery > No restrictions chuno.
  2. Redmi/Xiaomi: Settings > Apps > Permissions > Autostart > Termux ON.
  3. Recent apps me Termux card dabake pakdo > Lock (taala).
  4. Termux notification me Wake lock dikhna chahiye (ccs khud laga deta hai).
Advance: Android 12+ par phir bhi process mar jaye

PC se adb ke saath ye chalao (ek baar):

Ye step sirf Android (Termux) ke liye hai. PC par bas computer ko sleep me mat jane do (Power settings > Sleep: Never). ccs terminal band karne par bhi chalta rehta hai.

📦 APK banana

Apni website ya web app ka Android app (APK) banao. Dashboard ke APK tab se ya terminal se.

Ek baar ka setup (cloud build)

Termux par cloud build sabse aasan hai (Android SDK nahi chahiye). Pehle gh lagao aur GitHub me login karo:

Naya project aur build

  1. Naya project banao
  2. Build karo (APK apk-out folder me aati hai)
Termux me ek baar termux-setup-storage chalao to APK Downloads folder me bhi copy hogi.
Debug APK banti hai (Play Store release ke liye nahi). Local build sirf PC par chalta hai jahan JDK 17 aur Android SDK ho.

🧠 Advance

Jab basic aa jaye tab ye kaam aate hain.

Status, restart, band

Port badalna (agar koi port busy ho)

Default: dashboard 8787, proxy 8788, preview 8789. Env variable set karke badlo, phir ccs restart.

Claude Code ka version / apna GitHub repo

Termux par Claude Code 2.1.112 par pin hota hai (naye versions Termux par nahi chalte).

Smart proxy kya karta hai

Claude Code ek chhote proxy (127.0.0.1:8788) se baat karta hai. Model fail ho to proxy 2 baar khud retry karta hai, phir request roke rakhta hai (Claude ko error nahi dikhta). Dashboard par laal box aata hai, naya model chuno to kaam wahin se aage badhta hai. Home me "apne aap agla model lagao" on karo to ye bhi khud ho jata hai.

Claude ko APK skill dena

Plugins tab me APK Builder install karo, ya terminal me ye chalao. Phir Task tab me "is app ka APK banao" bolo.
